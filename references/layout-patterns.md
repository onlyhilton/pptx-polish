# 版式与排列范式

## 一、模板的六种版式

| 版式 | 用在什么页 | 判定信号 |
|---|---|---|
| **封面** | 全篇第 1 页 | 主标题 + 副标题 / 落款，无正文 |
| **目录** | 章节列表页 | 若干并列条目，无正文段落 |
| **标题加内容** | 绝大多数内容页 | 有标题 + 正文 / 图 / 图表 |
| **仅标题** | 只有标题的页 | 有标题，正文空或极短（< 30 字） |
| **空白页** | 纯图页 / 自由版式页 | 无标题结构，或整页由图片构成 |
| **封底** | 全篇最后 1 页 | 收束语 / 联系方式 / 二维码，无正文 |

判定顺序（自上而下，命中即停）：

1. 第 1 页 → 封面
2. 最后 1 页且无正文 → 封底
3. 有标题 + 有正文/图 → 标题加内容
4. 有标题 + 无正文 → 仅标题
5. 无标题 + 并列条目 → 目录
6. 其余 → 空白页

**注意**：判定依据是内容角色，不是原版式名。原稿常见的情况是所有页都用了"空白页"或默认 Office 版式，这时更需要这一步。

## 二、画布与安全区

默认画布 1280 × 720 px（16:9）。以模板实际定义为准。

| 区 | 垂直范围 | 说明 |
|---|---|---|
| A 标题块 | 0–120px | 主标题 32–40px bold |
| B 内容区 | 120–660px | 正文、图、图表、卡片 |
| C 页脚条 | 660–720px | 左侧标识 / 右侧页码 `NN / TOTAL` |

- 左右安全边距 60px（模板另有规定从其规定），上下 20px。
- **留白区不可侵犯**：A/C 区不得被 B 区内容挤占，安全区不得放内容。
- 可用内容宽度 = 1280 − 左右边距 × 2 = 1160px（按 60px 边距）。

## 三、排列范式

按内容之间的关系选范式，不按好看选。

### 3.1 横排（并列）

适用：等权重条目，无先后。

```
宽度 W = 1160，间距 g = 24
N 块时每块宽 = (W − (N−1)g) / N
N=2 → 568  |  N=3 → 371  |  N=4 → 272
```

### 3.2 纵排（时序）

适用：时间线、流程、有先后的步骤。

```
每行高 = (540 − (N−1)g) / N，g = 20
N=4 → 120  |  N=5 → 92
左侧可留 8px 时间轴竖线
```

### 3.3 田字格（2×2）

适用：4 个并列且体量相当的图或卡片。

```
块宽 = (1160 − 24) / 2 = 568
块高 = (540 − 24) / 2 = 258
```

### 3.4 九宫格（3×3）

适用：9 个并列条目 / 图标组。

```
块宽 = (1160 − 2×20) / 3 = 373
块高 = (540 − 2×20) / 3 = 166
```

### 3.5 阶梯

适用：递进、有阶段的路径（如成熟度分级、能力进阶）。

```
N 级，每级宽 = 1160 / N
第 i 级顶部 y = 120 + (N−1−i) × 上升步长（如 60px）
```

### 3.6 金字塔

适用：层级、包含关系（如 分层架构、策略层级）。

```
N 层，第 i 层（i 从顶=1 开始）宽 = 1160 × i / N，水平居中
层高 = 540 / N
```

### 3.7 左右分栏

适用：对比（前后 / 优劣）、图文对分。

```
两栏各宽 568，间距 24；或 图占 60%（696）+ 文占 35%（406）
```

## 四、图片排版规格

### 4.1 形式与数量

| 图片数 | 形式 | 布局 |
|---|---|---|
| 1 | 单图主视觉 / 半屏 | 占内容区 ≥ 40%，或左右对分 |
| 2 | 横排并列 / 左右对分 | 各 568 宽，间距 24 |
| 3 | 横排三等分 | 各 371 宽，间距 24 |
| 4 | 田字格 2×2 | 568×258 |
| 6 | 3×2 网格 | 373 宽，两行 |
| 9 | 九宫格 3×3 | 373×166 |

### 4.2 "整齐"的判定标准

- **统一高度**或**统一宽高比**，同一组内不得混用（这是"看起来乱"的头号原因）；
- 水平/垂直间距一致（同一组内偏差 ≤ 4px）；
- 边缘对齐：同列的左边缘对齐，同行的上边缘对齐（偏差 ≤ 4px）；
- **不得拉伸变形**：显示宽高比与原始像素宽高比偏差 > 5% 即不合格，应改用等比缩放 + 裁切；
- 圆角、描边、投影风格统一。

### 4.3 图片与文字的关系

- 图片应承担叙事功能（占有效面积、与正文耦合）；
- 禁止把 200×70 之类的小图塞在标题块右侧当装饰；
- 图片风格全篇统一（摄影 / 插画 / 3D 不混用，除非刻意声明）。

## 五、排版自检

- [ ] 每页内容占比 30%–85%，无溢出画布
- [ ] A/B/C 三区结构完整，留白区未被侵占
- [ ] 排列范式与内容关系匹配（并列→网格，递进→阶梯，层级→金字塔，时序→纵排）
- [ ] 同组图片统一高度/宽高比、等间距、边缘对齐
- [ ] 相邻页版式不重复，无"流水线感"
- [ ] 同类页面的标题位置、页码位置一致
