# 变更摘要模板

分步交付，每步结尾给一段**简短摘要**，不写长篇报告。用户要的是"改了什么、为什么、哪些没改"。

原则：结论先行，表格化，不写"首先/其次/总之"，不复述用户已经知道的事。

---

## Step 1 · 规范化摘要

```
## Step 1 规范化完成

产物：原名_1规范化.pptx

| 项 | 数量 |
|---|---|
| 标题归位到占位符 | N 页 |
| 新建 title 占位符 | N 个 |
| 删除的伪标题文本框 | N 个 |
| 清除的硬编码字体 | N 处 |
| 版式重映射 | N 页 |

### 逐页版式映射
| 原第 N 页 | 原版式 | 目标版式 | 判定依据 |
|---|---|---|---|
| 1 | 空白页 | 封面 | 首页、无正文 |

### 未执行项
- 第 N 页：<原因>（例如疑似标题不明确，保留原样待确认）
```

## Step 2 · 配图摘要

```
## Step 2 配图完成

产物：原名_2配图.pptx

| 处置 | 数量 | 说明 |
|---|---|---|
| 保留 | N | 参与统一规格 |
| 替换 | N | 图不对文 / 画质不足 |
| 删除 | N | 装饰小贴片 / 水印 |
| 新增 | N | 含真实素材 N 张、生图 N 张 |

### 排版形式
| 页 | 图片数 | 采用形式 | 统一规格 |
|---|---|---|---|
| 3 | 4 | 田字格 2×2 | 统一高 258px，间距 24px |

### 生图清单（须声明）
| 页 | 用途 | 生成方式 | 是否替代真实图 |
|---|---|---|---|
| 5 | 概念示意 | GPT-image-2 | 否 |
```

## Step 3 排版完成

```

```

---

## 交付前必答的三个问题

无论哪一步，摘要里必须能回答：

1. **改了什么** —— 具体到页与元素，不写"优化了排版"
2. **为什么改** —— 依据哪条规范（`audit-checklist.md` 的条目）
3. **哪些没改** —— 未执行项与原因，不许静默跳过
