# 审计清单与判定标准

按五步流水线组织（Step 5 是收口，必须在内容不再变动后跑）。审计原件时逐条过，交付前用最后一节自检。

判定依据以**可观察、可量化的指标**为准，不写"感觉不够专业"这类无法判定的条目。`scripts/audit_deck.py` 会自动判定其中带 ⚙ 的条目。

---

## Step 1 · 规范化审计

### 1.1 版式匹配

| 检查项 | 判定标准 | 严重度 |
|---|---|---|
| 版式不属于六种 | 页面版式不在 `封面/目录/标题加内容/仅标题/空白页/封底` 之内 | P1 |
| 版式与内容角色不符 | 例如内容页用了空白页、封面页用了标题加内容 | P1 ⚙ |
| 全篇版式单一 | 所有页都用同一个版式（通常是空白页）→ 换模板必乱 | P0 ⚙ |

### 1.2 标题归位（本步最高优先级）

| 检查项 | 判定标准 | 严重度 |
|---|---|---|
| ⚙ 标题在自由文本框里 | 有标题的页面，标题未写在 title 占位符中 | **P0** |
| ⚙ 页面无 title 占位符 | 有标题内容但页面不存在 title 占位符 | **P0** |
| 标题层级错位 | 副标题、章节名被当成主标题写进占位符 | P1 |

> **判定意义**：这是一切"换模板错位、黑底变白底"的根因。文本框不继承版式，主题一变位置与配色全废。

### 1.3 字体规范

| 检查项 | 判定标准 | 严重度 |
|---|---|---|
| ⚙ 硬编码字体 | run 上写了具体字体名（`a:latin`/`a:ea`/`a:cs`），未继承主题 | P1 |
| 字体家族数 | 全篇 > 2 套 | P1 ⚙ |
| 字号层级 | > 8 级，或层级之间无阶梯关系 | P2 ⚙ |
| 最小字号 | 正文 < 12pt，页脚 < 10pt | P1 ⚙ |
| 字号硬编码 | 逐页随机指定字号，未遵循模板层级 | P2 |

## Step 2 · 配图审计

| 检查项 | 判定标准 | 严重度 |
|---|---|---|
| 图不对文 | 图片内容与所在页文字无关 | P1 |
| 装饰小贴片 | 200×70 级别的图塞在标题块右侧 | P1 |
| 水印图 / 无关图 | 出现水印、样图、截图残留 | P1 |
| 有文无图 | 文字明确描述场景/产品但无对应配图 | P2 |
| 分辨率不足 | 图片原始像素长边 < 480 或面积 < 80000（⚙ 由 audit 标记 `low_quality`） | P2 |
| ⚙ 图片被放大 | **显示尺寸 > 原生像素**（必发虚；> 1.3 倍算严重）。注意与 `low_quality` 不同：小图标缩小显示没问题，大图放大才是事故 | P1 |
| 图片被拉伸 | 显示宽高比与原始比例偏差 > 5% | P1 |
| 同组未统一 | 同一组图片混用不同高度/宽高比 | P1 |

---

## Step 3 · 排版审计

| 检查项 | 判定标准 | 严重度 |
|---|---|---|
| ⚙ 元素出画布 | 形状几何超出画布边界 | P0 |
| ⚙ 内容压住版式 LOGO / 大装饰区 | 与版式或母版的**非占位符**装饰（logo、大色块）相交 ≥ 5%，且保留区面积 ≥ 3000 px² | P1 |
| ⚙ 内容与版式装饰条重叠 | 同上，但保留区面积 < 3000 px²（细装饰条，如标题下短横、分割线） | P2 |
| ⚙ 内容越出版式栅格 | 形状边界超出「本页版式 title/body 占位符」推导出的左右栅格 | P2 |
| 留白区被侵占（人工） | 内容进入标题区 / 页脚区或安全边距内，且不属上述可量化项 | P1 |
| 装饰重复（人工） | 页面上自绘的装饰与版式自带装饰叠了一层 | P2 |
| ⚙ 元素重叠 | 非刻意叠层的形状重叠比例 ≥ 30%（重点：完全重合的 100% 叠层） | P1 |
| 图文未对齐 | 同组图片边缘偏差 > 4px、间距不一致 > 4px | P1 |
| 范式与内容不符 | 并列内容用了阶梯、时序内容用了田字格 | P2 |
| 相邻页版式重复 | 连续 ≥ 2 页版式结构相同 | P2 |
| 密度不足 | 内容页正文 < 80 字 | P1 ⚙ |
| 内容占比失衡 | 内容占比 < 30% 或 > 85% | P1 |

---

## Step 4 · 配色审计

| 检查项 | 判定标准 | 严重度 |
|---|---|---|
| ⚙ 单页超三色 | 单页有彩色 > 3（黑白与中性灰不计入） | P1（≥ 6 种为 P0） |
| 非品牌色 | 出现 Reyee 蓝/绿及其明度派生之外的色相 | P2 |
| 角色色不统一 | 同一角色（标题/图表系列/页脚）在不同页用了不同色 | P2 |
| 对比不足 | 文字与背景明度差过低，实际不可读（黑底黑字） | P0 |
| 高饱和铺满 | 高饱和撞色铺满 ≥ 1/3 页面 | P1 |
| 硬编码色 | 颜色写死在元素上而非引用主题槽位 | P2 |

品牌色取值见 [brand-color.md](brand-color.md)。

## Step 5 · 标题单行审计

**口径**：标题绝不换行；放不下就缩字号。优先级高于"标题字号严格等于模板值"。

| 检查项 | 判定标准 | 严重度 |
|---|---|---|
| ⚙ **标题换行** | 标题占位符 / 标题槽位里的文字，PowerPoint 实测行数 ≥ 2（`TextRange.Lines().Count`） | **P0** |
| ⚙ **缩排过头（STALE）** | 现有 `fontScale` 比"刚好放得下"还小（上游写死，或标题后来改短了）→ 合格被改成没必要的小字 | P1 |
| ⚙ 标题缩排过量 | 为单行而缩到低于下限（默认 0.70，即 28pt→19.6pt）—— 应改报 `UNRESOLVED` 交用户定 | P1 |
| **标题含硬换行** | 标题里有 `<a:br/>` 或人工分段 —— 缩字号救不了，须改文字 | P1 |
| 缩放比未留余量 | `fontScale` 算成"恰好等于框宽"，PowerPoint 仍会换行 | P0 |
| 相邻标题字号跳变 | 同一版式下相邻页标题字号差 > 15%（缩排导致的观感断裂） | P2 |

**判定依据（写死，别混）**：

- 可用宽度 = `cx − lIns − rIns`，未声明时取 OOXML 默认 `各 7.2pt`。**不能用 `cx`**；
- 单行高 ≈ 字号 × 1.2（模板 `lnSpc` 均为 100%）；"设计上只放一行" = 框容行数 ≤ 1 **且**版式侧提示文本 ≤ 24 字；
- 行数只能由 PowerPoint 排版引擎给（`verify_title_lines.py`）。XML 度量**只能算缩放比，不能下结论**。

## 交付前自检表

### 红线复检（最高优先级）

- [ ] **R1** 页序与页数未变（五步都不增删页、不调换顺序）
- [ ] **R2** 所有数字、型号、参数、日期、客户名与原件逐字一致
- [ ] **R3** 原件信息点全部有归属，无整条丢失
- [ ] **R4** 真实图优先：产品图/数据图用真实素材，生图只用于概念/氛围图
- [ ] **R5** 原文件未被写入，输出为独立新文件
- [ ] **R6** 留白区未被侵占
- [ ] **R7 模板本体只读**：版式 / 母版 / 主题与模板逐形状、逐 run 属性一致
      （`verify_template_fidelity.py` 报 **P0 = 0**）；未删版式、未换主题、未改
      `p:ph` 槽位与 `defRPr` 的 `sz/b/i/u/spc/kern` 及 `latin/ea/cs`、颜色、背景图

### Step 1 规范化

- [ ] 有标题的页面，标题**全部**在 title 占位符里
- [ ] 全篇无硬编码字体
- [ ] 版式已匹配到模板六种版式之一
- [ ] 换模板试算：不会出现位置错位与黑底

### Step 2 配图

- [ ] 每张图有明确叙事功能，无装饰小贴片
- [ ] 同组图片统一高度/宽高比、等间距、边缘对齐
- [ ] 图片无拉伸变形
- [ ] 生图仅用于概念/氛围，未替代真实产品图或数据图

### Step 3 排版

- [ ] 每页内容占比 30%–85%，无溢出画布
- [ ] A/B/C 三区结构完整，留白未被侵占
- [ ] 排列范式与内容关系匹配
- [ ] 相邻页版式不重复

### Step 4 配色

- [ ] 每页有彩色 ≤ 3
- [ ] 出现的彩色均来自品牌色（或其明度派生）
- [ ] 全篇同角色同色
- [ ] 无黑底黑字这类不可读组合

### Step 5 标题单行（收口）

- [ ] `verify_title_lines.py` 报 **违规 = 0**（PowerPoint 自己数出来的行数，不是 XML 估算）
- [ ] `fix_title_oneline.py --check` 待处理 = 0（写完再跑一遍应报"已合规"，**幂等**）
- [ ] `HARD`（硬换行）项已改文字；`UNRESOLVED`（缩不到下限）与 `STALE`（缩过头）项已明确告知用户，
      **没有偷偷缩小、也没有顺手放大**
- [ ] 缩放只写 `fontScale`（未改声明字号），故 `verify_template_fidelity.py` 与
      `verify_pptx.py` 的"标题回归版式槽位"仍通过
- [ ] 渲染复核过标题带：**第二行不再压分隔线**，且标题框以外像素差异 = 0
- [ ] 交付说明里交代了"哪几页标题为单行而缩小了"（`verify_pptx.py` 会报 P1 列出）

### 交付

- [ ] **模板保真体检 P0 = 0**（`verify_template_fidelity.py`）——权威值是**模板文件**，不是产物自己的版式
- [ ] 分步交付时，每步产物可独立打开使用
- [ ] 变更摘要与实际改动一致，无夸大或遗漏
- [ ] 未执行项已写明原因

## 常见误判：四层体检的权威值不是同一个

| 工具 | 权威值 | 查什么 | 查不出什么 |
|---|---|---|---|
| `verify_pptx.py` | **产物自己的版式槽位** | 包结构、悬空引用、元素顺序、content-type、标题有没有回归版式 | **版式本身被改**（页面"回归"到改过的版式，照样报 P0=0） |
| `verify_template_fidelity.py` | **模板文件（`.thmx` / 模板 `.pptx`）** | 版式/母版/主题是否仍是模板格式 | 页面内容是否归位 |
| `verify_title_lines.py` | **PowerPoint 排版引擎** | 标题有没有换行（`TextRange.Lines().Count`） | 换行以外的一切；且**必须装有 PowerPoint** |
| `open_test.py` | PowerPoint 本体 | 包能不能被真机打开 | 任何语义问题 |

只跑第一个，"模板被篡改"这条路径全程静默 —— 2026-09-18 实测：同一份产物，`verify_pptx.py` P0=0，`verify_template_fidelity.py` P0=26。

> **"标题换行了没有"这件事，只有第三行能回答。** XML 度量（框宽 vs 文字宽度）与"渲染后数墨迹行"
> 都只是**预测**：前者与 PowerPoint 的断行有亚像素差；后者会被装饰线干扰，而且**溢出到框外的第二行
> 在裁切时就被切掉了**，看不见不等于没有。
