# Reyee 品牌配色规范

## 一、品牌色

| 名称 | RGB | HEX | 用途 |
|---|---|---|---|
| Reyee 蓝 | R0 G85 B205 | `#0055CD` | 主色：标题、主视觉、图表第一系列、强调块 |
| Reyee 绿 | R0 G220 B165 | `#00DCA5` | 强调色：正向数据、行动点、次级高亮 |

派生用法（不新增色相，只调明度）：

| 用途 | 做法 |
|---|---|
| 浅底块 | Reyee 蓝 / 绿加 90% 白（如 `#E5EEFA` 系） |
| 深压 | Reyee 蓝压深一档用于页脚条、分隔线 |
| 中性色 | 黑 `#000000`、白 `#FFFFFF`、灰阶（如 `#666666`、`#F5F5F5`）——**不计入三色上限** |

## 一·补、模板实测色值（改动前必读）

对 `assets/master/` 里两个 Reyee 模板做全包颜色普查（`scripts/analyze_template.py` + 全量 srgbClr 统计）的结果，与上表存在出入：

> **口径已确认：以规范值为准。** 模板里出现的 `1CDB93` / `00DB93` / `00DBA3` 是**制作模板时的误差**，不是另一套标准的绿。配色改造一律输出 `#0055CD` / `#00DCA5`；下面这些实测值的用途是**识别原稿里跑偏的绿**，也就是 `recolor_deck.py --map` 要替换掉的对象。

| 色值 | 出现位置 | 实际次数 | 说明 |
|---|---|---|---|
| `0055CD` | 浅色版 12 个 layout 的装饰形状 | 25 | **与规范一致**，浅色版主色 |
| `00DCA5` | — | **0** | **规范值，但两个模板包里均未出现** |
| `1CDB93` | 浅/深两版 | 9 | 模板实际用的绿 |
| `00DB93` | 浅/深两版 | 5 | 模板实际用的绿 |
| `00DBA3` | 浅/深两版 | 3 | 与规范值 `00DCA5` 最接近（差 G-1 / B-2） |
| `043CC1` | 母版 titleStyle + layout 标题 | 3 | 深一档的蓝，模板标题文字实际用它 |
| `002B67` | 仅浅色版 | 1 | 更深一档蓝 |
| `00DBFF` | 仅浅色版 | 2 | 青色 |
| `F26B43` | 浅/深两版 | 2 | 橙红，消极语义 |
| `FBAE40` | 深色版 | 20 | **深色版的主强调色（琥珀黄）** |
| `6E747A` / `50555A` | 两版 | 2 / 1 | 灰 |

两个模板的强调色逻辑**不同**：

- **浅色版**：主色 = 品牌蓝 `0055CD`；绿作辅助。
- **深色版**：**完全没有蓝**，改用 `FBAE40`（琥珀黄）+ `00DB93`（绿）。

**两个陷阱**：

1. **主题配色是 Office 默认，不是品牌色。** 两个模板的 `theme1.xml` 都是 `<a:clrScheme name="Office">`，`accent1 = 5B9BD5`（Office 蓝）。layout 里对 `accent1` 的引用（浅 15 次 / 深 12 次）会渲染成 Office 蓝。
   → 直接引用主题槽位会**跑色**；要用品牌色必须显式指定，或先把主题的 accent 槽位改成品牌色。
2. 装饰形状的 `accent1` 引用**多数被显式 `<a:solidFill>` 覆盖**，所以外观上不出错，但改主题时会被暴露。

## 二、单页三色规则

**单个页面颜色不超过三个（黑、白除外）。**

### 怎么数

计入数量的（有彩色）：

- 文字颜色（非黑非白）
- 形状填充、形状描边
- 线条、分隔条
- 图表系列色
- 图标着色

不计入的：

- 黑 `#000000`
- 白 `#FFFFFF`
- 中性灰（RGB 三通道极差 < 14，如 `#666666`、`#999999`、`#CCCCCC`）
- 图片本身的颜色（照片内容不算配色）

### 判定

| 情况 | 判定 |
|---|---|
| 单页有彩色的 hex ≤ 3 | 合格 |
| 单页 4–5 种 | 不合格（P1），需归并到 ≤ 3 |
| 单页 ≥ 6 种 | 不合格（P0）——基本能确定是原稿颜色失控 |
| 同一角色在不同页用了不同色 | 不合格（P2）——全篇同角色应同色 |

### 归并改法

1. **先归角色**：把页面上每个有色元素标为「主色 / 强调色 / 其他」；
2. 主色 → Reyee 蓝；强调色 → Reyee 绿；
3. 「其他」里能删的删（装饰性色块、无意义高亮），不能删的并到主色或中性灰；
4. 图表系列色多于 3 时，改为**同色不同明度**（如 Reyee 蓝的 3 档明度），而不是引入新色相。

## 三、与主题槽位的关系（重要）

配色有两种写法，后果完全不同：

| 写法 | 后果 |
|---|---|
| **硬编码**：run / 形状上直接写 `#0055CD` | 换模板时颜色**不会**跟着变，可能出现黑底黑字 |
| **主题色槽位**：引用 accent1 等主题槽位 | 换模板时颜色自动跟随新主题 |

规则：

- 已套用公司模板（主题已注入）时，**优先用主题色槽位**，把 Reyee 蓝 / 绿写进主题的 accent 槽位，页面元素引用槽位；
- 确需硬编码时，只允许出现在**不随模板变化的元素**上（如独立的品牌标识块）；
- 禁止在一页里混用「同一个色的硬编码 + 槽位引用」两种写法。

## 四、配色自检

- [ ] 每页有彩色的数量 ≤ 3
- [ ] 出现的彩色都来自品牌色（或其明度派生），没有自选色相
- [ ] 全篇同一角色用同一个色（标题、正文强调、图表系列、页脚）
- [ ] 文字与背景对比足够（深底浅字 / 浅底深字），不存在黑底黑字
- [ ] 优先使用主题色槽位而非硬编码
- [ ] 没有用高饱和撞色铺满 ≥ 1/3 页面
